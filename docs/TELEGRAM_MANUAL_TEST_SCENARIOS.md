# Telegram manual test scenarios

Status: not executed by this audit. Automated HTTP tests do not establish Telegram message delivery. No unsolicited Telegram messages were sent.

Use your own authorized Telegram account and the existing bot. Never paste the token into chat. Use only public blank official forms or their rendered images; do not upload personal documents.

## Common checks

1. Send `/start`, `/help`, `/language`; select English, French, Arabic and Derja in turn. Check menu language, sources and readable formatting.
2. Use `/cancel` during a pending request; check that the old reply is suppressed.
3. For each case below, compare the actual reply with the official passage and criteria in the full JSON matrix. A source link alone is insufficient. Record actual replies and verdicts locally; do not infer results from HTTP tests.
4. Check the passport declared-photos follow-up and residence-abroad follow-up explicitly. The bot must retain renewal and must not switch to a lost-passport procedure.
5. For every form, run `/form_check` and `/dossier_check` separately, with the official blank PDF and an image of that same blank form. Verify missing/unreadable/unverifiable states, supporting-source citations and no certification of completeness.
6. Test an unsupported file and a corrupt upload: safe error, no file contents in logs. Never create an invented official form.
